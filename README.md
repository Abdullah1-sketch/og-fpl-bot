# OG FPL Bot — v0.1

نسخة تجريبية لبوت عربي لتحديثات أسعار Fantasy Premier League.

## ماذا يفعل؟
1. يقرأ توقعات تغيّر السعر من LiveFPL.
2. ينبه عندما يتجاوز اللاعب عتبة محددة، افتراضيًا 90%.
3. يمنع تكرار نفس التنبيه للاعب.
4. يقرأ السعر الحقيقي من بيانات FPL الرسمية.
5. إذا تغيّر السعر فعليًا، ينشر تغريدة تأكيد.
6. يضيف #FPL تلقائيًا.

## مهم
الإعداد الافتراضي `DRY_RUN=true`، لذلك لن ينشر أي شيء في X أثناء الاختبار.

## التثبيت
```bash
pip install -r requirements.txt
cp .env.example .env
```

ضع مفاتيح X داخل `.env` فقط، ولا تشارك الملف.

## تجربة
```bash
python bot.py
```

في وضع DRY RUN سيطبع التغريدات المقترحة فقط.

## مصادر البيانات
- LiveFPL predictor: https://livefpl.us/api/prices.json
- Official FPL data: https://fantasy.premierleague.com/api/bootstrap-static/
